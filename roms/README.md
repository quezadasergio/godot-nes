Put SNES ROMs here (`.sfc`, `.smc`, `.fig`). Files without an extension are also picked up.

The basename is matched with art in `game-images/`:

- `roms/DonkeyKongCountry.sfc` (or `roms/DonkeyKongCountry`)
- `game-images/DonkeyKongCountry.jpg`

Restart the project (or return to the menu) to rescan. Prefer a `.sfc` / `.smc` extension so Godot and the exporter treat the file as a ROM.
